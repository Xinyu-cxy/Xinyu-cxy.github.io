# Constrained Optimization

## 1. Standard Form

$$\begin{aligned}
\min_{x \in \mathbb{R}^d} \quad & f(x) \\
\text{subject to} \quad & g_i(x) \le 0, \quad i = 1, \dots, m \quad \text{(inequality constraints)} \\
& h_j(x) = 0, \quad j = 1, \dots, p \quad \text{(equality constraints)}
\end{aligned}$$

In vector form:
$$g(x) = \begin{pmatrix} g_1(x) \\ \vdots \\ g_m(x) \end{pmatrix}, \quad h(x) = \begin{pmatrix} h_1(x) \\ \vdots \\ h_p(x) \end{pmatrix}$$

* Feasible Set:=
  $$C = \{x \in \mathbb{R}^d : g(x) \le 0, \, h(x) = 0\}$$
* Active Constraint: $g_i(x) = 0$, $h_j(x) = 0$
* Inactive Constraint: $g_i(x) < 0$

### Example: Hard-Margin Support Vector Machine (SVM)
$$\begin{aligned}
\min_{x \in \mathbb{R}^d} \quad & \frac{1}{2}\|x\|^2 \\
\text{subject to} \quad & y_i a_i^T x \ge 1, \quad i = 1, \dots, n
\end{aligned}$$

## 2. Optimality Condition

* Unconstrained: $\nabla f(x^*) = 0$ (implies a global minimum if $f$ is convex).

## 3. Feasible Directions & Projected Gradient Descent

### Feasible Direction
* A vector $s$ is a feasible direction at $x \in C$ if there is $\bar{t} > 0$ such that $x + ts \in C$ for every $t \in [0, \bar{t}]$.
* Necessary Condition: If $f$ is differentiable at a local minimizer $x^*$ over $C$, then:
  $$\nabla f(x^*)^T s \ge 0$$
  for every feasible direction $s$ at $x^*$. At an interior minimizer, $\nabla f(x^*) = 0$.
* If Convex: Let $C \subseteq \mathbb{R}^d$ be nonempty and convex, let $f: \mathbb{R}^d \to \mathbb{R}$ be differentiable, and let $x^* \in C$. If $x^*$ is a local minimizer over $C$, then:
  $$\nabla f(x^*)^T (v - x^*) \ge 0 \quad \text{for every } v \in C$$

### Euclidean Projection
For a nonempty, closed, convex set $C \subseteq \mathbb{R}^d$, the Euclidean projection of $u \in \mathbb{R}^d$ is:
$$P_C(u) = \arg\min_{x \in C} \frac{1}{2}\|x - u\|^2$$

* Existence & Uniqueness: The projection exists and is unique; $P_C(u)$ denotes a single point.
* Characterization Theorem: Let $C$ be nonempty, closed, and convex. For $u \in \mathbb{R}^d$ and $z \in C$:
  $$z = P_C(u) \iff (u - z)^T (v - z) \le 0 \quad \text{for every } v \in C$$
* Non-expansiveness: For a nonempty, closed, convex set $C$ and any $u, v \in \mathbb{R}^d$:
  $$\|P_C(u) - P_C(v)\| \le \|u - v\|$$

### How to Calculate $P_C$?

1. Linear Subspace:
   $$C_1 = \text{span}\{q_1, \dots, q_r\}$$
   Let $Q = [q_1, \dots, q_r] \in \mathbb{R}^{d \times r}$ be orthonormal (i.e., $q_i^T q_j = 0$ for $i \neq j$, $q_i^T q_i = 1$, so $Q^T Q = I_r$).
   $$P_{C_1}(u) = \sum_{i=1}^r (q_i^T u) q_i = Q Q^T u$$

2. Euclidean Unit Ball:
   $$C_2 = \{x \in \mathbb{R}^d : \|x\| \le 1\}$$
   $$P_{C_2}(u) = \begin{cases} \frac{u}{\|u\|} & \text{if } \|u\| > 1 \\ u & \text{if } \|u\| \le 1 \end{cases}$$

3. Probability Simplex ($\Delta_d$):  
   By the definition of $P_C$ (finding the closest point in $C$ to $u$):
   $$\min_{x} \frac{1}{2}\|x - u\|^2 \quad \text{s.t.} \quad x_i \ge 0 \text{ for all } i, \quad \mathbf{1}^T x = 1$$
   The projection is given component-wise by:
   $$(P_{\Delta_d}(u))_i = \max\{u_i - \tau, 0\}, \quad \text{where } \sum_{i=1}^d \max\{u_i - \tau, 0\} = 1$$
   Algorithm: Sort $u_{(1)} \ge \dots \ge u_{(d)}$ and choose $r \in \{1, \dots, d\}$ such that:
   $$\tau = \frac{\sum_{i=1}^r u_{(i)} - 1}{r}, \quad \text{and} \quad u_{(r)} > \tau \ge u_{(r+1)}$$

### Projected Gradient Descent (PGD)

Update rule with step size $\alpha > 0$:
$$u_k = x_k - \alpha \nabla f(x_k)$$
$$x_{k+1} = P_C(u_k)$$

Equivalently:
$$x_{k+1} \in \arg\min_{x \in C} \left\{ f(x_k) + \nabla f(x_k)^T (x - x_k) + \frac{1}{2\alpha}\|x - x_k\|^2 \right\}$$

* Gradient Mapping:
  $$G_\alpha(x) = \frac{1}{\alpha}\left(x - P_C(x - \alpha \nabla f(x))\right)$$
* Optimality Equivalence:
  $$G_\alpha(x) = 0 \iff \nabla f(x)^T (v - x) \ge 0 \quad \text{for every } v \in C$$
  For convex $f$, this is equivalent to global optimality over $C$.

#### Algorithm: Projected Gradient Descent
```algorithm
for $k = 0, 1, \dots$ do
    $z_k \leftarrow P_C(x_k - \alpha \nabla f(x_k))$
    if $\|x_k - z_k\| / \alpha \le \epsilon$ then
        return $x_k$
    end if
    $x_{k+1} \leftarrow z_k$
end for
```

#### Properties & Convergence
* Descent Lemma: Let $C \subseteq \mathbb{R}^d$ be nonempty, closed, and convex, and let $f: \mathbb{R}^d \to \mathbb{R}$ be $L$-smooth with $L > 0$. For $x \in C$, $\alpha > 0$, and $z = P_C(x - \alpha \nabla f(x))$:
  $$f(z) \le f(x) - \left(\frac{1}{\alpha} - \frac{L}{2}\right)\|z - x\|^2$$
* Sufficient Decrease ($\alpha = \frac{1}{L}$):
  $$f(x) - f(z) \ge \frac{1}{2L} \|G_{1/L}(x)\|^2$$
* Convergence Rate: Let $C \subseteq \mathbb{R}^d$ be nonempty, closed, and convex, and let $f: \mathbb{R}^d \to \mathbb{R}$ be convex and $L$-smooth for some $L > 0$. Assume a minimizer $x^* \in C$ exists. Starting from $x_0 \in C$, use $\alpha = \frac{1}{L}$ and $\epsilon = 0$. For every $k \ge 1$:
  $$f(x_k) - f(x^*) \le \frac{L\|x_0 - x^*\|^2}{2k}$$

## 4. Equality Constraints

### Case Study: Linear Equality Constraint
* Constraint: $h(x) = x_1 + x_2 - 1 = 0$
* Goal: $\min f(x)$
* Condition: $\implies \nabla f(x^*) + \nu^* \nabla h(x^*) = 0$ for some $\nu^* \in \mathbb{R}$.

### Nonlinear Equality Constraints
Let $h: \mathbb{R}^d \to \mathbb{R}^p$ be continuously differentiable and $C = \{x : h(x) = 0\}$. *(Consider a curve $\gamma(t): \mathbb{R} \to \mathbb{R}^d$ on the manifold such that $h(\gamma(t)) = 0$)*.

Consider:
$$\min_{x \in \mathbb{R}^d} f(x) \quad \text{subject to} \quad h_i(x) = 0 \text{ for } i = 1, \dots, p$$
where $f, h_1, \dots, h_p$ are continuously differentiable.

Write $h = (h_1, \dots, h_p)^T$, and define the Jacobian matrix:
$$J_h(x) = \begin{bmatrix} \nabla h_1(x), \dots, \nabla h_p(x) \end{bmatrix}^T$$

* Lagrange Multiplier Theorem: If $x^*$ is a local minimizer and $\text{rank}(J_h(x^*)) = p$, then there exists $\nu^* \in \mathbb{R}^p$ such that:
  $$\nabla f(x^*) + J_h(x^*)^T \nu^* = \nabla f(x^*) + \sum_{i=1}^p \nu_i^* \nabla h_i(x^*) = 0$$
(necessary not sufficient)

## 5. The Lagrangian & KKT Conditions

For the constrained problem:
$$\begin{aligned}
\min_{x \in \mathbb{R}^d} \quad & f(x) \\
\text{subject to} \quad & g_i(x) \le 0, \quad i = 1, \dots, m \\
& h_j(x) = 0, \quad j = 1, \dots, p
\end{aligned}$$

Its Lagrangian is:
$$\mathcal{L}(x, \lambda, \nu) = f(x) + \lambda^T g(x) + \nu^T h(x)$$
where $\lambda \in \mathbb{R}^m$ ($\lambda \ge 0$) and $\nu \in \mathbb{R}^p$.

The gradient with respect to $x$ is:
$$\nabla_x \mathcal{L}(x, \lambda, \nu) = \nabla f(x) + \sum_{i=1}^m \lambda_i \nabla g_i(x) + \sum_{j=1}^p \nu_j \nabla h_j(x)$$

### KKT Conditions
1. Stationarity: $\nabla_x \mathcal{L}(x, \lambda, \nu) = 0$
2. Primal Feasibility: $g_i(x) \le 0, \quad h_j(x) = 0$
3. Dual Feasibility: $\lambda_i \ge 0$
4. Complementary Slackness: $\lambda_i g_i(x) = 0 \quad \text{for all } i$

* A point $x \in \mathbb{R}^d$ is a KKT point if there exist $\lambda \in \mathbb{R}^m, \nu \in \mathbb{R}^p$ such that $(x, \lambda, \nu)$ satisfies the KKT conditions.
* KKT points are candidates, but need not be local minimizers.

### LICQ (Linear Independence Constraint Qualification)
* Definition: LICQ holds at a feasible $x$ if the gradients of the active constraints
  $$\{\nabla g_i(x) : i \in \mathcal{A}(x)\} \cup \{\nabla h_j(x) : j = 1, \dots, p\}$$
  are linearly independent.
* Theorem: Suppose $f, g_i, h_j$ are continuously differentiable near a local minimizer $x^*$. If LICQ holds at $x^*$, then there exist multipliers $\lambda^*, \nu^*$ satisfying all KKT conditions.
* *Note:* LICQ is a sufficient regularity condition; its failure does not by itself rule out the existence of KKT multipliers.

### Steps for Solving a KKT System
1. Standardize the constraints: Write inequalities as $g_i(x) \le 0$ (e.g., $\alpha^T x \ge \beta \implies \beta - \alpha^T x \le 0$).
2. Form the Lagrangian: $\mathcal{L} = f + \lambda^T g + \nu^T h$ with $\lambda \ge 0$.
3. Solve every active-set case: For each possible active inequality set, set $g_i(x) = 0$ for its members and $\lambda_i = 0$ for the others (along with $h(x) = 0$).
4. Verify each candidate: Check primal feasibility, multiplier signs ($\lambda \ge 0$), and complementary slackness.
5. Collect all KKT points: Optimality still needs justification.

## 6. When Do KKT Conditions Certify a Global Minimum?

* Theorem: Suppose $f, g_1, \dots, g_m : \mathbb{R}^d \to \mathbb{R}$ are differentiable and convex, and each $h_j$ is affine. If $(x^*, \lambda^*, \nu^*)$ satisfies KKT, then $x^*$ is a global minimizer.
* *Note:* This does not require LICQ.
* If $\lambda^*, \nu^*$ are known:
  $$\min_{x \in \mathbb{R}^d} \mathcal{L}(x, \lambda^*, \nu^*) = f(x^*)$$

## 7. The Lagrangian Dual Function

The Lagrangian dual function $q: \mathbb{R}_+^m \times \mathbb{R}^p \to \mathbb{R} \cup \{-\infty\}$ is given by:
$$q(\lambda, \nu) := \inf_{x \in \mathbb{R}^d} \mathcal{L}(x, \lambda, \nu)$$
for $\lambda \in \mathbb{R}_+^m$ and $\nu \in \mathbb{R}^p$, where $\mathbb{R}_+^m = \{x \in \mathbb{R}^m \mid x_i \ge 0, \, \forall i = 1, \dots, m\}$.  

*(Note: When $\mathcal{L}$ is convex in $x$, finding the infimum is an unconstrained convex optimization problem solved via $\frac{\partial \mathcal{L}}{\partial x} = 0$).*

* Primal Problem: $p^* = \inf_{x \in C} f(x)$
* Dual Problem: $d^* = \max_{\lambda \ge 0, \, \nu \in \mathbb{R}^p} q(\lambda, \nu)$

### Weak Duality
For any feasible $x \in C$ and $\lambda \ge 0$:
$$q(\lambda, \nu) \le \mathcal{L}(x, \lambda, \nu) \le f(x)$$
Taking the supremum over $(\lambda, \nu)$ and infimum over $x$:
$$q(\lambda, \nu) \le d^* \le p^* \le f(x)$$
* Weak duality always holds (does not require convexity).
* $p^* - d^*$ is called the duality gap.

## 8. Concavity and Strong Duality

* Concave Function: A function $F: D \to \mathbb{R}$ on a convex set $D \subseteq \mathbb{R}^d$ is concave iff:
  $$F(\theta u + (1 - \theta)v) \ge \theta F(u) + (1 - \theta)F(v)$$
  for all $u, v \in D$ and $\theta \in [0, 1]$.
* Concavity of Dual Function: The dual function $q$ is always concave on $\mathbb{R}_+^m \times \mathbb{R}^p$.
  $$\max_{\lambda \ge 0, \, \nu} q(\lambda, \nu) \iff \min_{\lambda \ge 0, \, \nu} -q(\lambda, \nu) \quad \text{(convex optimization problem)}$$

### Strong Duality & Slater's Condition
* Strong Duality means zero duality gap: $d^* = p^*$.
* Slater's Condition: Suppose $f, g_1, \dots, g_m : \mathbb{R}^d \to \mathbb{R}$ are convex, each $h_j$ is affine, and $p^* \in \mathbb{R}$. If there exists a strictly feasible point $\bar{x}$ such that:
  $$g_i(\bar{x}) < 0 \quad \text{for every } i \quad \text{and} \quad h(\bar{x}) = 0$$
  then $d^* = p^*$ and the dual optimum is attained.
* *Note:* Slater's condition is sufficient, not necessary.

## 9. Penalty and Barrier Methods

### Common Penalty & Barrier Functions

| Type | Equalities ($h(x) = 0$) | Inequalities ($g(x) \le 0$) |
|  |  |  |
| Quadratic | $\frac{\rho}{2} \sum_j h_j(x)^2$ | $\frac{\rho}{2} \sum_i [g_i(x)]_+^2$ |
| Absolute | $\rho \sum_j \|h_j(x)\|$ | $\rho \sum_i [g_i(x)]_+$ |
| Logarithmic | — | $-\rho \sum_i \log(-g_i(x))$ |

where $[t]_+ := \max\{t, 0\}$.

### Quadratic Penalty Method
* Example: Define the penalized objective for $\rho > 0$:
  $$Q_\rho(x) = f(x) + \frac{\rho}{2}\|h(x)\|^2$$
* If $x^*$ is a minimizer of $Q_\rho$ and $h(x^*) = 0$, then $x^*$ is a minimizer of $f(x)$ subject to $h(x) = 0$.

#### Algorithm: Quadratic Penalty Method
```algorithm
Require: $\rho_0 > 0$, $\gamma > 1$, $\epsilon > 0$
for $k = 0, 1, \dots$ do
    $x_{k+1} \in \arg\min_{x \in \mathbb{R}^d} Q_{\rho_k}(x)$   $\text{(solved via Newton's method or GD)}$
    if $\|h(x_{k+1})\| \le \epsilon$ then
        return $x_{k+1}$
    end if
    $\rho_{k+1} \leftarrow \gamma \rho_k$
end for
```

#### Convergence & Limitations
* Convergence Theorem: Suppose $f: \mathbb{R}^d \to \mathbb{R}$ and $h: \mathbb{R}^d \to \mathbb{R}^p$ are continuous, and $\min_{h(x)=0} f(x)$ has a global minimizer $x^*$. Let $\rho_k > 0$ with $\rho_k \to \infty$, and let:
  $$x_{k+1} \in \arg\min_{x \in \mathbb{R}^d} \left[ f(x) + \frac{\rho_k}{2}\|h(x)\|^2 \right]$$
  Assume the iterates remain bounded ($\|x_k\| \le R$ for some $R > 0$). Then:
  $$\|h(x_k)\| \to 0, \quad f(x_k) \to f(x^*)$$
* Motivation for Augmented Lagrangian (ALM):
  For the constrained minimizer $x^*$ of $f(x)$, generally $\nabla f(x^*) \neq 0$ (since $x^*$ often lies on the boundary). Thus:
  * If $\nabla Q_{\rho_k}(x) = 0$, we must have $h(x) \neq 0$ for finite $\rho_k$.
  * Conversely, if $h(x^*) = 0$, then $\nabla Q_\rho(x^*) = \nabla f(x^*) \neq 0$, so $x^*$ is not a stationary point of $Q_\rho$. (This requires $\rho \to \infty$, leading to ill-conditioning).

### Augmented Lagrangian Method (ALM)
Consider the equality-constrained problem ($h(x) = 0$ only). The Augmented Lagrangian is:
$$\mathcal{L}_\rho(x, \nu) = f(x) + \nu^T h(x) + \frac{\rho}{2}\|h(x)\|^2, \quad \nu \in \mathbb{R}^p, \, \rho > 0$$

* Minimization Condition:
  $$\nabla_x \mathcal{L}_\rho(x_{k+1}, \nu_k) = \nabla f(x_{k+1}) + J_h(x_{k+1})^T (\nu_k + \rho h(x_{k+1})) = 0$$
* Comparing with the KKT stationarity condition $\nabla f(x^*) + J_h(x^*)^T \nu^* = 0$, this motivates the dual multiplier update:
  $$\nu_{k+1} = \nu_k + \rho h(x_{k+1})$$

#### Algorithm: Augmented Lagrangian Method (ALM)
```algorithm
for $k = 0, 1, \dots$ do
    $x_{k+1} \in \arg\min_x \mathcal{L}_\rho(x, \nu_k)$
    $\nu_{k+1} \leftarrow \nu_k + \rho h(x_{k+1})$
    if $\|h(x_{k+1})\| \le \epsilon$ then
        return $(x_{k+1}, \nu_{k+1})$
    end if
end for
```
