# Introduction & Unconstrained Optimization

## Basic vector calculus

1. $\|u\|=\sqrt{\langle u,u\rangle},\quad \langle u,v\rangle = u^T v$

2. $\nabla f(x)=\left(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial_d}\right)^T,\quad f'(x;v)=\nabla f(x)^T v$

3. $F(x)=g(h(x)),\quad \nabla f(x)=J_h(x)^T \nabla g(h(x))$

4. $f(x+s)=f(x)+\nabla f(x)^T s+\frac12 s^T \nabla^2 f(x)s + o(\|s\|^2)$

## Unconstrained Optimization

### goal

$$\min_{x\in\mathbb R^d} f(x)$$

Questions:

- in which direction should we move
- how far should we move
- when can we stop, how can we tell whether the algorithm returns a good enough solution

### Optimality conditions

a) stationary: $\nabla f(x^*) = 0$

b) Let $f:\mathbb R^d\to\mathbb R$ be differentiable at $x^*$, if $x^*$ is a local minimizer, then $\nabla f(x^*)=0$  

If $f:\mathbb R^d\to\mathbb R$ twice continuously differentiable, $\nabla^2 f(x)\in\mathbb R^{d\times d}$ is symmetric.  

$\lambda_{\min}I \preceq Q \preceq \lambda_{\max}I$

$Q\succeq 0$ iff all eigenvalues are nonnegative

- $x^*$ is a local minimizer, then $\nabla f(x^*)=0$ and $\nabla^2 f(x^*)\succeq 0$.

- If $\nabla f(x^*)=0$ and $\nabla^2 f(x^*)\succ 0$, then $x^*$ is a strict local minimizer.

### Which direction should we move?

Move in a direction that decreases the objective
most rapidly.

a) prove:  

$$f(x_k+tp)=f(x_k)+t\nabla f(x_k)^T p + o(t)$$
We require $\nabla f(x_k)^T p <0$
$$\min_{\|p\|=1} \nabla f(x_k)^T p$$

Cauchy-Schwarz:
$$|u^T v| \le \|u\| \|v\|$$

$$|\nabla f(x_k)^T p| \le \|\nabla f(x_k)\|$$

$$ \nabla f(x_k)^T p \ge -\|\nabla f(x_k)\|$$

achieved at:
$$p=-\frac{\nabla f(x_k)}{\|\nabla f(x_k)\|}$$

b) Cauchy-Schwarz: $|u^T v| \le \|u\|\|v\|$

### How should we choose step sizes

a) $L$-Lipschitz: A map $G:D\to\mathbb R^m$ is $L$-Lipschitz on $D$, with $L\ge0$, if
$$\|G(u)-G(v)\| \le L\|u-v\|,\quad \forall u,v\in D$$

b) $L$-smooth: A differentiable $f:\mathbb R^d\to\mathbb R$ is $L$-smooth when
$$\|\nabla f(u)-\nabla f(v)\| \le L\|u-v\|,\quad \forall u,v\in\mathbb R^d$$

c) If $f$ is $L$-smooth, then
$$f(v)\le f(u)+\nabla f(u)^T(v-u)+\frac L2\|v-u\|^2$$

gradient descent decreases $f$ when $0<\alpha<\frac{2}{L}$

convenient choice $\alpha=\frac1L \Rightarrow f(x_{k+1}) \le f(x_k)-\frac{1}{2L}\|\nabla f(x_k)\|^2$

d) $f$ is bounded below and $L$-smooth for some $L>0$.
Run gradient descent with $\varepsilon=0$ and $\alpha_k=\frac1L$.
For every $k\ge1$,
$$\min_{0\le j<k}\|\nabla f(x_j)\|^2 \le \frac{2L(f(x_0)-f^*)}{k},\quad f^*=\inf_x f(x)$$

At least one of the first $k$ iterates has a small gradient.
A small gradient does not, by itself, certify a local or global minimizer.

### e) Convex

- A set $C\subseteq\mathbb R^d$ is convex if $u,v\in C,\theta\in[0,1]$
$$\theta u+(1-\theta)v \in C$$

- Let $C$ be convex. A function $f:C\to\mathbb R$ is convex if for every $u,v\in C$, and $\theta\in[0,1]$
$$f(\theta u+(1-\theta)v) \le \theta f(u)+(1-\theta)f(v)$$

- Convex function rules:  
$f_1,\dots,f_r$ are convex, $\gamma_1,\dots,\gamma_r\ge0$, $\sum \gamma_i f_i$ is convex  
$g:\mathbb R^m\to\mathbb R$ is convex, $M\in\mathbb R^{m\times d}, q\in\mathbb R^m$, then $g(Mx+q)$ is convex  
$f_1,\dots,f_r$ are convex, $\max f_i(x)$ is convex

- $f$ is convex if and only if
$$f(v)\ge f(u)+\nabla f(u)^T(v-u),\quad \forall u,v\in C$$

- Let $C\subseteq\mathbb R^d$ be open and convex, let $f:C\to\mathbb R$ be twice continuously differentiable, then
$f$ is convex on $C \iff \nabla^2 f(x)\succeq0$ for every $x\in C$

- Let $f:\mathbb R^d\to\mathbb R$ be differentiable and convex,
then $x^*$ is a global minimizer $\iff \nabla f(x^*)=0$

- Let $f$ be convex and $L$-smooth for some $L>0$, and let $x^*$ be a minimizer. Run gradient descent with $\varepsilon=0$ and $\alpha_k=\frac1L$. For every $k\ge1$,
$$f(x_k)-f(x^*)\le \frac{L\|x_0-x^*\|^2}{2k}=O(k^{-1})$$
This bound guarantees an objective gap at most $\delta$ after $O(\frac1\delta)$ iterations.

### f) $\mu$-strongly convex

- A differentiable function $f:\mathbb R^d\to\mathbb R$ is $\mu$-strongly convex if
$$f(v)\ge f(u)+\nabla f(u)^T(v-u)+\frac{\mu}{2}\|v-u\|^2, \quad \forall u,v\in \mathbb R^d$$  

- A strongly convex function is lower bounded globally by a quadratic function.  
$f$ is $\mu$-strongly convex $\iff g(x)=f(x)-\frac\mu2\|x\|^2$ is convex.

- $f:\mathbb R^d\to\mathbb R$ be twice continuously differentiable, and let $0<\mu\le L$. Then $f$ is $\mu$-strongly convex and $L$-smooth if and only if
$$\mu I \preceq \nabla^2 f(x) \preceq L I,\quad \forall x\in\mathbb R^d$$
$\kappa=\frac L\mu \ge1$ is called the condition number.
A problem is ill-conditioned if $\kappa$ is large.

- Let $f$ be $\mu$-strongly convex and $L$-smooth, and let $x^*$ be its unique minimizer.
Run gradient descent with $\varepsilon=0$ and $\alpha_k=\frac1L$.
For every $k\ge0$,
$$f(x_k)-f(x^*) \le \left(1-\frac\mu L\right)^k (f(x_0)-f(x^*))$$

- Polyak-Lojasiewicz inequality for strong convexity:
if $f$ is $\mu$-strongly convex, then $\|\nabla f(x)\|^2 \ge 2\mu(f(x)-f^*)$  
$\rightarrow$Since $\frac\mu L=\frac1\kappa$, reducing the objective gap by factor $\delta\in(0,1)$ takes $O\left(\kappa\log\frac1\delta\right)$ iterations.

- For $f(x)=\frac12 x^T Qx -b^T x$, where $Q=Q^T\succ0$.
$\nabla f(x)=Qx-b,\quad \nabla^2 f(x)=Q$, therefore
$\mu=\lambda_{\min}(Q),\ L=\lambda_{\max}(Q),\quad \kappa(f)=\frac L\mu=\frac{\lambda_{\max}(Q)}{\lambda_{\min}(Q)}$

$\Rightarrow$For $f(x)=\frac12 x^T Qx,\ Q=\mathrm{diag}(\lambda_1,\dots,\lambda_d)$
Can we scale the update of each coordinate using its own curvature?

## Newton's Method

$$f(x_k+p)\approx f(x_k)+\nabla f(x_k)^T p+\frac12 p^T \nabla^2 f(x_k)p$$

$$g_k(p)=f(x_k+p) \approx f(x_k)+\nabla f(x_k)^T p+\frac12 p^T\nabla^2 f(x_k)p$$

$$\nabla g_k(p_k)=\nabla f(x_k)+\nabla^2 f(x_k)p_k=0$$

$$p_k = -\left(\nabla^2 f(x_k)\right)^{-1}\nabla f(x_k)$$
minimizes the quadratic model.

$$x_{k+1}=x_k+p_k$$

For $f(x)=\frac12 x^T Qx -b^T x$,
$$x_{k+1}=x_k-Q^{-1}(Qx_k-b)=Q^{-1}b=x^*$$
$$\nabla f(x_{k+1})=0$$

### Matrix 2-norm

$$\|A\|=\max_{\|z\|=1}\|Az\|,\quad A\in\mathbb R^{m\times d},\ z\in\mathbb R^d$$

- $\|Az\| \le \|A\|\|z\|$  
If $A\in\mathbb R^{d\times d}$ is symmetric, then $\|A\|=\max_i|\lambda_i(A)|$.  
In particular, if $A\succeq0$, then $\|A\|=\lambda_{\max}(A)$.

- Hessian is $\rho$-Lipschitz on $D\subseteq\mathbb R^d$, with $\rho\ge0$ if
$$\|\nabla^2 f(u)-\nabla^2 f(v)\| \le \rho\|u-v\|$$

- Let $f$ be twice continuously differentiable near $x^*$, with $\nabla f(x^*)=0$ and $\nabla^2 f(x^*)\succ0$.  
Suppose its Hessian is $\rho$-Lipschitz on a neighbourhood of $x^*$. If $x_0$ is sufficiently close to $x^*$, Newton's iterates are well defined and satisfy
$$\|x_{k+1}-x^*\| \le C\|x_k-x^*\|^2$$
for some constant $C>0$ and every $k\ge0$.

### $\Rightarrow$Choosing step size

Exact line search:
$$\alpha_k^{\text{exact}}=\arg\min_{\alpha\ge0} f(x_k+\alpha p_k)$$

eg. for $\frac12 x^T Qx-b^T x,\ \alpha^{\text{exact}}=\frac{g_k^T g_k}{g_k^T Q g_k},\ g_k=\nabla f(x_k)$

If $\phi_k(\alpha)=f(x_k+\alpha p_k)$ is convex, we can use a method such as bisection to find its minimizer, find $\phi'=0$.

- Armijo condition: fix $c_A\in(0,1)$. A step size $\alpha>0$ is acceptable if
$$f(x_k+\alpha p_k) \le f(x_k)+c_A \alpha \nabla f(x_k)^T p_k$$

Let $\bar\alpha>0$ and $c_A,\eta\in(0,1)$. If $f$ is continuously differentiable near $x_k$ and $p_k$ is a descent direction, then the backtracking loop terminates after finite reductions.
