## Basic Definition

### Discriminative learning algorithms

- Idea: finds a line that separates examples
- Learning target: learns $P(y|x)$ / $h_\theta(x)$ = 0(1)

### Generative learning algorithm

- Idea: check different classes and see where the classes are at
- Learning target: learns $P(x|y)$ — what are the features like given class $y$
- Auxiliary term: $P(y)$ (class prior)

### Bayes Rule

$$P(y=1|x) = \frac{P(x|y=1)P(y=1)}{P(x)}$$

$$P(x) = P(x|y=1)P(y=1) + P(x|y=0)P(y=0)$$

## Gaussian Discriminant Analysis (GDA)

Assumptions:
$x \in \mathbb{R}^n$ (drop $x_0=1$ convention, not $\mathbb{R}^{n+1}$)
Assume $P(x|y)$ is Gaussian

### Multivariate Gaussian Distribution

$$z \sim N(\vec{\mu},\Sigma)$$
$$ z = \begin{pmatrix}x_1 \\ x_2 \\ \vdots \\ x_n\end{pmatrix} = \begin{pmatrix}z_1 \\ z_2 \\ \vdots \\ z_n\end{pmatrix} (fetures)$$
$$z \in \mathbb{R}^n,\ \vec{\mu} \in \mathbb{R}^n,\ \Sigma \in \mathbb{R}^{n \times n}$$

Expectation and Covariance:
$$E(z) = \vec{\mu} = \begin{pmatrix}\mu_1 \\ \mu_2 \\ \vdots \\ \mu_n\end{pmatrix}$$
$$
\begin{align*}
\mathrm{Cov}(z) &= E\left[(z-\mu)(z-\mu)^T\right] \\
&= E[zz^T] - (Ez)(Ez)^T
\end{align*}
$$

PDF of multivariate Gaussian:
$$P(z) = \frac{1}{(2\pi)^{\frac{n}{2}} |\Sigma|^{\frac{1}{2}}} \exp\left(-\frac{1}{2}(x-\mu)^T \Sigma^{-1}(x-\mu)\right)$$

### GDA Model Distribution

$$P(x|y=0) = \frac{1}{(2\pi)^{\frac{n}{2}} |\Sigma|^{\frac{1}{2}}} \exp\left(-\frac{1}{2}(x-\mu_0)^T \Sigma^{-1}(x-\mu_0)\right)$$
$$P(x|y=1) = \frac{1}{(2\pi)^{\frac{n}{2}} |\Sigma|^{\frac{1}{2}}} \exp\left(-\frac{1}{2}(x-\mu_1)^T \Sigma^{-1}(x-\mu_1)\right)$$
$$P(y) = \phi^y (1-\phi)^{1-y}$$
$\mu_1$ and $\mu_2$: different x distribution for different y

### GDA Parameters

$\mu_0 \in \mathbb{R}^n,\ \mu_1 \in \mathbb{R}^n,\ \Sigma \in \mathbb{R}^{n \times n},\ \phi \in \mathbb{R}$  
Note: Shared covariance matrix $\Sigma$ for two classes.

### Training Objective: Maximize Joint Likelihood

Training set: $\{(x^{(1)},y^{(1)}), \dots, (x^{(m)},y^{(m)})\}$
Joint likelihood function:
$$
\begin{align*}
\mathcal{L}(\phi, \mu_0, \mu_1, \Sigma) &= \prod_{i=1}^m P(x^{(i)}, y^{(i)}; \phi, \mu_0, \mu_1, \Sigma) \\
&= \prod_{i=1}^m P(x^{(i)} | y^{(i)}) P(y^{(i)})
\end{align*}
$$

#### Contrast with Discriminative Model

Discriminative model maximizes conditional likelihood:
$$\mathcal{L}(\theta) = \prod_{i=1}^m P(y^{(i)} | x^{(i)}; \theta)$$

### MLE conclusion (Max $\ell(\cdot) = \log\mathcal{L}(\cdot)$)

$$\phi = \frac{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 1\}}{m}$$

$\mu_0$: average vector of samples where $y=0$
$$\mu_0 = \frac{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 0\} x^{(i)}}{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 0\}}$$

$\mu_1$: average vector of samples where $y=1$
$$\mu_1 = \frac{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 1\} x^{(i)}}{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 1\}}$$

Shared covariance matrix:
$$\Sigma = \frac{1}{m} \sum_{i=1}^m \left(x^{(i)} - \mu_{y^{(i)}}\right)\left(x^{(i)} - \mu_{y^{(i)}}\right)^T$$

### Prediction Rule

Goal: $\max_y P(y|x)$
$$
\begin{align*}
\arg\max_y P(y|x) &= \arg\max_y \frac{P(x|y)P(y)}{P(x)} \\
&= \arg\max_y P(x|y)P(y)
\end{align*}
$$
$P(x)$ is constant w.r.t $y$, can be ignored in argmax.  
$P(x|y=0)$, $P(x|y=1)$, $P(y)$'s value are calculated above

### Compare GDA and Logistic Regression

For fixed $\phi,\mu_0,\mu_1,\Sigma$, plot $P(y=1 | x; \phi,\mu_0,\mu_1,\Sigma)$ as function of $x$

#### Model Assumptions

GDA strong assumptions:
$$
\begin{cases}
x|y=0 \sim N(\mu_0,\Sigma) \\
x|y=1 \sim N(\mu_1,\Sigma) \\
y \sim \mathrm{Ber}(\phi)
\end{cases}
$$
These assumptions derive logistic form: $P(y=1|x) = \frac{1}{1+e^{-\theta^T x}}$

Logistic regression has weaker assumptions.

#### Performance Comparison

- If $x|y$ truly Gaussian: GDA performs better
- If $x|y$ not Gaussian: GDA performs poorly

Example:
$x|y=1 \sim \mathrm{Poisson}(\lambda_1)$
$x|y=0 \sim \mathrm{Poisson}(\lambda_2)$
Still results in logistic-shaped $P(y=1|x)$

## Naive Bayes (Generative)

### Example: Email Classification

Feature vector setup:
Take top 10k words as features
$x \in \{0,1\}^n,\ n=10k$
$x_i = \mathbb{1}\{\text{word }i\text{ appears in email}\}$

Goal: model $P(x|y), P(y)$
Problem: $2^{10k}$ possible values of $x$, too many parameters without extra assumptions.

### Naive Bayes Assumption

Conditional independence given $y$
$$P(x_1,\dots,x_{10k} | y) = \prod_{j=1}^{10k} P(x_j | y)$$
Intuition: Seeing word B does not depend on whether word A appears in email, given label $y$.

### Naive Bayes Parameters

$$\phi_{j|y=1} = P(x_j=1 | y=1)$$
$$\phi_{j|y=0} = P(x_j=1 | y=0)$$
$$\phi_y = P(y=1)$$

### Joint Likelihood

$$\mathcal{L}(\phi_y, \phi_{j|y}) = \prod_{i=1}^m P(x^{(i)}, y^{(i)}; \phi_y, \phi_{j|y})$$

### MLE Estimation

$$\phi_y = \frac{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 1\}}{m}$$
$$\phi_{j|y=1} = \frac{\sum_{i=1}^m \mathbb{1}\{x_j^{(i)}=1,\ y^{(i)}=1\}}{\sum_{i=1}^m \mathbb{1}\{y^{(i)} = 1\}}$$
